# Installation

### 1. Create an Expo project

Run the following command to create a new Expo project using the blank template:

```bash
npx create-expo-app@latest TestApp --template expo-template-blank@57
```

### 2. Install web support

To run the app in a browser, install the required dependencies:

```bash
npx expo install react-native-web react-dom
```

### 3. Start the app

Navigate to the project folder and start Expo:

```bash
cd TestApp
npx expo start
```

Follow the terminal instructions to open the app in your browser or on a device.

### 4. Test the example

Copy the `App.js` file from this folder and use it to **replace the `App.js` generated by Expo**.

Restart the app if necessary to test the example.

> **Note:** Other installation methods and Expo templates are available. These instructions use `expo-template-blank@57`, so your setup may differ if you use another template or Expo version.
